# PSP Cheat DB Manager for Android 0.7.11

Native Android port based on PSP Cheat DB Manager Windows v0.6.15. This mobile build focuses on local CWCheat database management, searchable game records, merging/deduplication, source selection, and `.ini`/database export using Android's Storage Access Framework.

## Build the APK

Open this folder in Android Studio and choose **Build > Build APK(s)**. The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`. Or run `gradlew.bat assembleDebug` on Windows (the wrapper downloads Gradle if needed). The APK can be installed from Android's file manager; Android may ask you to allow installs from that source.

The project uses Android Gradle Plugin 8.9.1, Kotlin 2.0.21, compile SDK 35, and minimum Android 6.0 (API 23). A Windows build can also be made from PowerShell with the included Gradle wrapper, once generated by Android Studio.

## Features

- Choose Add PSP Game to add one ISO/PBP/CHD or scan a complete folder tree for PSP game files. Folder scans run in the background, show progress, populate the library, and start automatic cover searches in the background; a warning explains large scans may take several minutes. Scanning needs Android permission to the chosen folder. Individual-file selection and typing a game title or ID remain available. Selecting a catalog match fills in the ID. The title catalog comes from [PPSSPP's Redump list](https://github.com/hrydgard/ppsspp/blob/master/assets/redump.csv) and is cached on the device. If an image filename has no serial, the app also tries matching its title against the catalog; otherwise enter the ID manually.
- Import CWCheat `.db`, `.ini`, `.txt`, and ZIP archives from device storage. Archive processing runs in the background with compressed and expanded size limits.
- Merge into the app's private database, deduplicating identical names/code sequences.
- Search a game by its PSP title ID; use the game picker to extract an ID from the selected ISO/PBP filename when present. The filename is used for ID detection; verify it before exporting.
- Filter cheat names for 60 FPS, 4:3, 3:2, and ultrawide labels.
- Export selected cheats or all cheats for the currently selected game as plain CWCheat text. Whole-app database export is omitted in this version to keep large exports from freezing the app. The selected-mod PPSSPP export merges with an existing `PSP/Cheats/cheat.db`, retains its parsed game entries, skips duplicate codes, and saves a verified timestamped backup of the prior file before replacement.
- Download the two user-selectable sources: CWCheat Database Plus by Saramagrean and PPSSPP_workarounds by LunaMoo. Downloads require explicit confirmation.
- Themes are chosen from a two-column tile gallery in Settings: Matrix, Ghost Protocol, Vice City, Kratos, Midnight Club, Wipeout, Liberty City, Patapon, Neon Genesis, Arctic Camo, Stealth Ops, and Afterburner. Each tile uses its theme colors and icon; Ghost Protocol is the fresh-install and reset default.
- The full game library, Home, Recents, and Favorites have separate screens. Home returns to the main screen with the last opened game selected. The library can show games from a scanned folder plus recently opened titles; Recents and Favorites are limited to those respective lists. Game lists can sort by recently added, title ascending/descending, or region. Cheat lists can sort by name, category, or code-line count.
- A compact main screen keeps game selection and lookup up front; database, filters, and export controls are grouped under a collapsible panel.
- Security defaults disable app-data backup, block cleartext network traffic, use Android system certificate validation, encrypt optional SteamGridDB credentials with Android Keystore, and use Android’s scoped folder picker instead of broad storage access. Source downloads require confirmation and imports are size-limited; imported community cheats are unverified. The Android app remembers the export folder using the system folder picker. Game cheat INIs export with only the game ID as the filename (for example `UCUS98744.ini`). For the PPSSPP database export, choose PPSSPP's `PSP/Cheats` folder.
- Export completion displays the exact filename, mod count, code-line count, and remembered destination. The `cheat.db` success prompt reminds users to open the game's PPSSPP Cheats screen and tap **Import from cheat.db**; simply placing the file does not import it. The app creates `.ini` files as binary documents and checks/renames the provider result so it does not append `.txt`.
- The mod screen keeps a larger search/list area and pins the selected/all export buttons at the bottom.
- Launcher icon uses a full-size blue adaptive foreground with Android launcher masking and a legacy fallback; the user's original blue artwork remains the branding reference.
- The landscape game and mod screens keep game details and file actions at left, filterable cheat rows in the center, icon-only section shortcuts at right, and a fixed export bar. Ghost Protocol is the fresh-install and reset theme; saved legacy theme choices migrate to Ghost Protocol or the closest new preset.
- Title suggestions show the country/region as a separate labeled line beside the game ID. Selecting an ID or a matching ISO/PBP/CHD opens a dedicated mod list screen; a valid typed ID opens it automatically.
- Dedicated Settings page for themes, source controls, remembered folders, and full fresh-install reset. First launch opens a full-screen, five-slide setup guide covering PPSSPP installation and cheat setup, the game folder, single-file versus full-folder import, an optional encrypted SteamGridDB key, and individually selectable cheat sources. CWCheat Database Plus is marked recommended; all source downloads still require confirmation.
- Recent and Favorites show only games the user opened or starred. The game display has six layouts—Horizontal, Snug, Stacked, Compact Details, 12-Game Grid (three columns by four rows), and Cover Carousel. Compact Details shows selected-for-export and available mod counts; the carousel enlarges the focused or hovered cover. Change layouts from the VIEW control in the game display or cycle them with L2/LT/ZL.
- Choosing the PPSSPP PSP/Cheats folder scans its existing game `.ini` files in the background, then reports per-game and folder-wide mod counts. `_C1` entries are counted as enabled; `_C0` entries are counted as disabled. The scan runs again on resume, after the app writes an INI, and when Android reports folder changes; while the app is open, file metadata is checked every four seconds.
- Box-art lookup uses the selected game's technical title and region against the actual [Libretro PSP Named_Boxarts index](https://thumbnails.libretro.com/Sony%20-%20PlayStation%20Portable/Named_Boxarts/), then downloads and caches one cover type. The index is cached on-device to speed up later lookups, and the cover updates in place as soon as it arrives.
- Optional SteamGridDB fallback is available in Settings → Cover Art. Users can add their own SteamGridDB API key (not their Steam password); it is stored encrypted on-device and is only used when Libretro has no match.
- Compact layout rules adapt the controls to 4:3 and narrower screens while 16:9 landscape keeps the full labels. Game cover cards can be Horizontal, Snug, or Stacked from Settings → Cover Art.
- Right-side navigation uses accessible icons instead of text labels. Games opens the full game gallery with cover art and a shortcut to each game’s cheat list; Favorites, Recent, and Settings remain directly accessible. The filter picker keeps 4:3 available while removing it from the quick-filter chips; Other remains selectable inside the picker. A Select All Visible control selects or clears the currently filtered cheat rows.
- Source downloads show a themed progress dialog with percentage when the server reports the file size, and completed imports, exports, and scans appear briefly in a corner notification. Dialogs and pop-up menus use the active theme. Controller settings separate Switch, PlayStation, and Xbox button labels; each screen shows matching controller hints for select, back, sort, filter, quick favorite, and settings. R1/RB/R quick-favorites the current or focused game.
- Home restores the selected game's cached cover art after returning from another screen, then refreshes it in the background if needed. The redundant Browse Games button was removed from the main and cheat screens.
- Selecting or opening a game automatically starts box-art lookup. The status changes when artwork loads or no match is found. The first-run guide explains that this independent tool works with PPSSPP's Cheats feature, states that it is not affiliated with PPSSPP or its developers, and links to PPSSPP's official download page.

## Mobile port scope

Android uses the system document picker instead of remembered desktop folder paths. The experimental PSP ISO/MIPS learning and patch generation UI from the Windows build is not included in this initial mobile port. The Android app manages existing cheat references and exports them; it does not apply codes to a running game. Filenames can identify a game ID when they contain a serial; otherwise enter the ID manually. Verify every game's region/revision before using exported codes. This is a debug-signed APK intended for personal installation; publishing to Google Play requires a separately signed release build.
